## 推荐观看顺序（入门 → 进阶）

1. **入门必看**：地球脉动 II → 蓝色星球 II → 七个世界，一个星球
2. **补全旗舰**：地球脉动 I/III → 冰冻星球 I/II → 绿色星球 → 完美星球
3. **看故事**：猎捕 → 王朝 → 企鹅群里有特务 → 荒野间谍
4. **看地域**：非洲 → 美丽中国 → 亚洲 → 南太平洋
5. **考古补课**：生命（2009）→ 生命的故事 → 生命的进化（1979）
6. **关心地球**：我们的星球 → 地球上的一段生命旅程 → 气候变化：事实真相
