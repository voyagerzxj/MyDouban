# 条目模板

新建板块或往表格里加条目时，从这里复制格式。状态符号：⬜ 想看 🟨 在看 ✅ 已看 ❌ 弃了。

```markdown
| 片名 | 导演/出品 | 年份 | 豆瓣 | 状态 | ⭐ 我的评分 | 备注 |
|---|---|---|---|---|---|---|
| | | | | ⬜ | | |
```

## 单个作品的详细笔记（值得长评时单开一页）

```markdown

title: 《作品名》
description: 一句话概括
published: true
tags: 电影, 长评
editor: markdown
---

# 《作品名》

- **状态**：✅ 已看（2026-06-12）
- **我的评分**：⭐ 8/10
- **信息**：导演 / 年份 / 豆瓣分

## 短评

## 摘录 / 截图
```

## 新建页面的频道约定

- 路径用英文小写（如 `music/albums`、`games/played`），层级随意；
- 标题（frontmatter 的 `title`）用中文；
- 加上 `tags` 方便全站按标签筛选。
